  • Table: pos_vatcode
  • Columns: 12
  • Indexes: 3 (business/is_active, business/vat_rate, business/hs_code_chapter)
  • Constraints: 1 unique (business, code)

API Endpoints:
  • Base route: /api/vat-codes/
  • CRUD: GET (list), POST (create), GET (detail), PUT/PATCH (update), DELETE
  • Custom: by_rate, excisable, products

Model Hierarchy:
  • VATCode inherits from: CacheInvalidationMixin, AuditModelMixin, models.Model
  • Product links to VATCode via: ForeignKey (nullable, cascading)

Performance:
  • Query optimization: select_related used
  • Caching: Automatic via CacheInvalidationMixin
  • Pagination: Supported on all list endpoints

🚀 QUICK START
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Apply Migration:
   cd d:\V2POS\posd
   python manage.py migrate pos 0099_add_vat_code_system

2. Create Default VAT Codes:
   python manage.py shell
   >>> from pos.models import VATCode, Business
   >>> business = Business.objects.first()
   >>> VATCode.objects.create(business=business, code='VAT-STD', 
   ...                        name='Standard (16%)', vat_rate=16.00)

3. Access Admin:
   http://localhost:8000/admin/pos/vatcode/

4. Use API:
   curl http://localhost:8000/api/vat-codes/ \
     -H "Authorization: Bearer TOKEN"
