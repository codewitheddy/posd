## 🛠️ Quick Commands

### Documentation
```bash
# View in browser (if markdown viewer installed)
start README.md              # Windows
open README.md               # Mac
xdg-open README.md           # Linux

# Search documentation
grep -r "search term" *.md   # Linux/Mac
findstr /s "search term" *.md # Windows
```

### Application
```bash
# Start server
python manage.py runserver

# Create admin
python manage.py createsuperuser

# Load data
python manage.py seed_data

# Check system
python manage.py check
```
