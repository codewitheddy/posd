## 🚀 Getting Started

### Quick Setup (5 Minutes)
```bash
# 1. Migrations already applied ✓
# 2. Payment methods setup ✓

# 3. Create expense categories
python manage.py shell
>>> from pos.models import ExpenseCategory
>>> for cat in ['Rent', 'Utilities', 'Salaries', 'Supplies', 'Marketing']:
...     ExpenseCategory.objects.get_or_create(name=cat)

# 4. Configure business settings
# Go to: Admin > Business Settings

# 5. Create your first customer
# Go to: Customers > Add Customer

# 6. Start selling!
# Go to: New Sale
```
