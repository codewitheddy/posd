## 🎨 Customization

Want to change the look? Edit `pos_system/settings.py`:

### Change Theme
```python
JAZZMIN_UI_TWEAKS = {
    "theme": "darkly",  # Try: darkly, cyborg, slate, superhero
}
```

### Add Logo
```python
JAZZMIN_SETTINGS = {
    "site_logo": "path/to/logo.png",
}
```

### Change Colors
```python
JAZZMIN_UI_TWEAKS = {
    "sidebar": "sidebar-dark-primary",
    "navbar": "navbar-dark",
}
```
