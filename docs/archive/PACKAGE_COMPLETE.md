### For End Users (Installing)

**Step 1: Extract ZIP**
```
1. Right-click POS_System_Portable_v1.3.0.zip
2. Select "Extract All..."
3. Choose destination (e.g., C:\POS_System)
4. Click "Extract"
```

**Step 2: Install Python (if needed)**
```
1. Check if Python installed:
   - Open Command Prompt
   - Type: python --version
   
2. If not installed:
   - Download from: https://www.python.org/downloads/
   - Install Python 3.8 or higher
   - ✅ CHECK "Add Python to PATH"
   - Restart computer
```

**Step 3: Run Setup**
```
1. Open extracted folder
2. Double-click: PORTABLE_SETUP.bat
3. Wait 2-5 minutes for installation
4. Choose to load sample data (Y/N)
```

**Step 4: Start System**
```
1. Double-click: START_POS.bat
2. Browser opens automatically
3. System ready at: http://127.0.0.1:8000
```

**Step 5: Create Admin User**
```
1. In terminal window, follow prompts:
   - Username: admin
   - Email: (optional)
   - Password: (choose strong password)
   
2. Login at: http://127.0.0.1:8000/admin
```
