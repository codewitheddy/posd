Bulk Upload Products

How to Use Bulk Upload
  1. Download the CSV template or export existing products
  2. Fill in product details in the CSV file
  3. Upload the completed CSV file
  4. System will create new products or update existing ones
Step 1: Get CSV Template
Download Template Export Existing Products

Template: Empty template with sample data
Export: Your current products as CSV

Step 2: CSV Format

Your CSV file supports these column headers (case-insensitive, flexible naming):

Column Required Description Example
name Yes Product name Coca Cola 500ml
product_code No Internal SKU / Product Code BEV001
barcode No Barcode / EAN / UPC for scanner 5449000000996
category No Category name (auto-created if new) Beverages
cost_price Optional* Buying / Cost Price (KES). *If omitted, defaults to selling price. 55.00
unit_price Yes Selling Price (KES) 80.00
stock_quantity No Initial stock count (default: 0) 50
low_stock_threshold No Low stock alert level (default: 10) 10

Tips for Success
  • Use Excel or Google Sheets to edit CSV files
  • Save as CSV (Comma delimited) format
  • Don't include extra columns
  • Keep column names exactly as shown
  • Use decimal point (.) for prices, not comma
  • Leave product_code empty if not using barcodes
  • Test with a few products first
