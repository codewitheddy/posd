INSTALLATION
================================================================================

OPTION 1: Using Installer (Recommended)
----------------------------------------
1. Run POS_System_Setup.exe
2. Follow installation wizard
3. Launch from Start Menu or Desktop icon

OPTION 2: Portable Version
---------------------------
1. Extract ZIP file to any folder
2. Open the extracted folder
3. Double-click POS_System.exe or START_POS.bat

================================================================================
FIRST TIME SETUP
================================================================================

1. CREATE ADMIN USER
   - When prompted, enter:
     * Username
     * Email (optional)
     * Password
   - Remember these credentials!

2. LOAD SAMPLE DATA (Optional)
   - Adds 20 sample products
   - Good for testing
   - Can be deleted later

3. START USING
   - Browser opens automatically
   - Login with admin credentials
   - Begin adding products and making sales

================================================================================
QUICK START
================================================================================

DASHBOARD
---------
- View today's sales and revenue
- Check stock alerts
- Quick access to all features

ADDING PRODUCTS
---------------
1. Click "Products" in menu
2. Click "Add Product"
3. Fill in details:
   - Name (required)
   - Product Code (optional, for barcode scanning)
   - Category
   - Price (required)
   - Stock Quantity
   - Low Stock Alert Level
4. Click "Save Product"

MAKING A SALE
-------------
1. Click "New Sale" in menu
2. Select products by:
   - Clicking product cards, OR
   - Scanning barcode, OR
   - Typing product code
3. Adjust quantities if needed
4. Apply discount (optional)
5. Review totals
6. Click "Complete Sale"
7. Print or download invoice

MANAGING STOCK
--------------
1. Click "Stock" in menu
2. View all products with stock levels
3. Click "Adjust" to add/remove stock
4. Select adjustment type:
   - Restock (adding new inventory)
   - Damage/Loss (removing damaged items)
   - Customer Return (adding returned items)
   - Stock Correction (fixing errors)
5. Enter quantity and reason
6. Click "Adjust Stock"

BULK UPLOAD PRODUCTS
--------------------
1. Click "Products" → "Bulk Upload"
2. Download CSV template
3. Fill in product details in Excel
4. Save as CSV file
5. Upload the CSV file
6. Review results

VIEWING REPORTS
---------------
1. Click "Reports" in menu
2. Select date
3. View:
   - Total sales
   - VAT collected
   - Discounts given
   - Transaction list
4. Click "View" on any transaction for details

================================================================================
DATA BACKUP
================================================================================

IMPORTANT: Backup your data regularly!

BACKUP METHOD 1: Copy Database File
------------------------------------
1. Close POS System
2. Navigate to installation folder
3. Copy "db.sqlite3" file
4. Save to safe location (USB, cloud, etc.)

BACKUP METHOD 2: Export Products
---------------------------------
1. Go to Products → Export CSV
2. Save CSV file
3. Keep in safe location

RESTORE:
--------
1. Close POS System
2. Replace "db.sqlite3" with backup file
3. Restart POS System

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Application won't start
SOLUTION:
- Check if port 8000 is available
- Run as Administrator
- Check antivirus/firewall settings

PROBLEM: Browser doesn't open
SOLUTION:
- Manually open: http://127.0.0.1:8000
- Check default browser settings

PROBLEM: Can't login
SOLUTION:
- Verify username and password
- Reset password using admin panel
- Create new superuser if needed

PROBLEM: Products not showing
SOLUTION:
- Check if products exist in database
- Load sample data for testing
- Check browser console for errors

PROBLEM: Barcode scanner not working
SOLUTION:
- Ensure scanner is plugged in
- Test scanner in Notepad
- Check scanner configuration
- Try manual product code entry

PROBLEM: Stock not deducting
SOLUTION:
- Check if sale completed successfully
- View stock history for product
- Verify stock adjustment records

PROBLEM: Database errors
SOLUTION:
- Close and restart application
- Restore from backup
- Contact support

================================================================================
TIPS & BEST PRACTICES
================================================================================

1. REGULAR BACKUPS
   - Backup database daily
   - Keep multiple backup copies
   - Test restore process

2. STOCK MANAGEMENT
   - Set realistic low stock thresholds
   - Check alerts daily
   - Perform physical counts regularly

3. PRODUCT CODES
   - Use consistent format
   - Keep codes short and memorable
   - Document your coding system

4. CATEGORIES
   - Organize products logically
   - Use clear category names
   - Don't create too many categories

5. PRICING
   - Double-check prices before saving
   - Use bulk upload for price updates
   - Keep price history if needed

6. SALES
   - Complete sales promptly
   - Print receipts for customers
   - Review daily reports

7. SECURITY
   - Use strong passwords
   - Don't share admin credentials
   - Log out when not in use
