🚀 HOW TO ACCESS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Restart the Django server
   If running: Press CTRL + C
   Then run: python manage.py runserver

Step 2: Go to Marid POS main page
   http://localhost:8000/b/default/

Step 3: Look at left sidebar → Inventory section
   You'll see "VAT Codes" link

Step 4: Click "VAT Codes"
   Opens admin interface to manage VAT codes


✨ WHAT YOU CAN DO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

From the VAT Codes page:

✓ View all VAT codes
  See complete list with rates, descriptions, status

✓ Create new VAT code
  Click "Add VAT Code" button
  Fill form and save

✓ Edit existing VAT code
  Click on any code to edit
  Update fields and save

✓ Delete VAT code
  Click delete button
  Confirm deletion

✓ Search VAT codes
  Use search box to find by code, name, or description

✓ Filter VAT codes
  Filter by:
  • Active/Inactive status
  • VAT rate
  • Excisable products
  • Business
  • Creation date
