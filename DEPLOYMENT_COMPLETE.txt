Step 1: Go to Admin → Products
        http://localhost:8000/admin/pos/product/

Step 2: Click on a product to edit

Step 3: Scroll to "Tax Settings" section

Step 4: From dropdown "VAT Code", select desired code
        • VAT-STD for standard products
        • VAT-ZERO for unprocessed foods
        • VAT-EXEMPT for exempt services
        • VAT-EXCISE for alcohol/tobacco

Task: Create Custom VAT Code

Step 1: Go to Admin → VAT Codes → Add VAT Code
        http://localhost:8000/admin/pos/vatcode/add/

Step 2: Fill in the form:
        • Code: e.g., "CUSTOM-RATE"
        • Name: e.g., "Custom Rate (14%)"
        • VAT Rate: 14.00
        • Description: When to use this code
        • Is Active: Check to make available

Step 3: Click Save


🔧 API EXAMPLES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Get all VAT codes:
curl http://localhost:8000/api/vat-codes/ \
  -H "Authorization: Bearer YOUR_TOKEN"

Create a new VAT code:
curl -X POST http://localhost:8000/api/vat-codes/ \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "code": "VAT-CUSTOM",
    "name": "Custom Rate (14%)",
    "vat_rate": "14.00",
    "description": "Custom VAT rate for specific products"
  }'

Get VAT codes by rate:
curl http://localhost:8000/api/vat-codes/by_rate/?rate=0.00 \
  -H "Authorization: Bearer YOUR_TOKEN"

Get excisable VAT codes:
curl http://localhost:8000/api/vat-codes/excisable/ \
  -H "Authorization: Bearer YOUR_TOKEN"

Get products using a VAT code:
curl http://localhost:8000/api/vat-codes/1/products/ \
  -H "Authorization: Bearer YOUR_TOKEN"
